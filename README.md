# sabo-mutu

A software engineering company focused on creating high-quality solutions for clients.

## Repository Structure

This repository contains:
- **docs/**: Project documentation, including product specs, architecture, and testing strategy
- **apps/**: Application code with web and API components
- **packages/**: Core packages and libraries
- **tests/**: Testing infrastructure
- **\.github/workflows/**: CI/CD workflows

## Getting Started

To get started with this project:

1. Clone the repository
2. Run `git submodule update --init --recursive` if there are submodules
3. Follow the onboarding documentation in `docs/specs/onboarding.md`

## Documentation
